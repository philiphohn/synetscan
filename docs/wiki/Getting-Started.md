# Getting Started

Everything you need to get SynetScan from the download page to a first list of devices, in about five minutes.

1. **[Requirements and Compatibility](Requirements-and-Compatibility)**: which DSM versions, models and accounts work, and what the package needs from the NAS.
2. **[Installing SynetScan](Installation)**: download the `.spk` and install it with Package Center → Manual Install.
3. **[Quick Start: Your First Scan](First-Scan)**: open the app, run the first scan and understand the baseline.

Afterwards, continue with the [Interface Tour](Interface-Tour) or go straight to [Reviewing Newly Discovered Devices](Reviewing-New-Devices).
